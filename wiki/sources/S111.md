Program and container format A compiled network reaches the engine as two layered files. The upper one is a dispatch descriptor, a FlatBuffer that names the operations and binds the buffers. Beneath it the hardware container is a Mach-O-shaped file with the magic 0xbeefface, holding the register-write program and the weight banks.
