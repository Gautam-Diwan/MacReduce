**Reading scope:** HTML text extraction: gp3 storage, baseline performance, extra IOPS/throughput and prorating examples.

## Findings and limitations

**Source-reported:** EBS storage is separately billed and prorated. The worked example uses USD 0.08/GB-month; extra provisioned performance has separate charges.

**Limitations:** The example is not a universal region quote. No price asserted for the recommended Mac storage performance; obtain a region-specific quote before renting. No external benchmark performance has been reproduced by this reading.
