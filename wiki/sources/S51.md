## What this page is for

Cross-chip deployment¶ ANEForge compiles a tensor graph for any Apple Neural Engine generation from one host, and predicts how that graph will behave on the target chip without owning it. Apple's ANE compiler is the same code across chips; everything that differs between an M1 and an M5 is per-chip target data plus the MinimumFamily<N> op-capability floors.
