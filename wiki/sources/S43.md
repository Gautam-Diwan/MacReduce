## What this page is for

aneforge - frontend API reference¶ aneforge is a graph -> compile -> run frontend for the Apple Neural Engine. You build a small tensor graph from Python, compile it into ONE fused e5rt program, and call the result on the ANE. Fusing is the point: the ANE penalises many tiny dispatches, so a whole subgraph becomes a single program. For the underlying hardware op surface and dtype limits see capabilities.md. import numpy as np
