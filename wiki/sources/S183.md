## Findings and limitations

**Source-reported / source-code inspection:** The compatibility client retains a supplied client instance. Flower owns concurrent RPC and transport, but stock strategy/server behavior alone does not enforce fixed-cohort durable commits. MacReduce wraps it with signed envelopes, validation and checkpoints. Public client wrapper starts analytics threads even when sending is disabled.

**Limitations:** Saved bytes are explicitly a source-excerpt extraction with verified wheel URL/hash and upstream license, not a complete wheel. Compatibility APIs are deprecated/version-specific. Modern object chunking does not apply to the selected compatibility path. A GitHub release-tag lookup failed; the published wheel was used instead. No generic library supplies the missing standalone ANE Qwen backend.
