## What this page is for

Hardware results (ANE leaderboard)¶ Contributors run one benchmark suite on their own Macs and submit the results, so the project keeps a growing cross-chip record of what the Neural Engine actually does on each Apple Silicon machine. Each submission is a fingerprinted JSON file (chip, model, cores, memory, macOS, power state, and the exact commit it ran on). Where to see it¶ ANE leaderboard on Hugging Face: an interactive, sortable table that reads the live data from main.
