## What this page is for

Training on the ANE¶ ANEForge is not inference-only. aneforge/autograd.py is a small reverse-mode autograd in which both the forward and the backward pass compile to, and run on, the Apple Neural Engine through the e5rt path. A model's weights, gradients, and the optimizer update all live as ANE graph ops; the host computes only a scalar learning rate, samples minibatches, and reads results at checkpoints. Training runs on the same e5rt dispatch backend as the rest of ANEForg
