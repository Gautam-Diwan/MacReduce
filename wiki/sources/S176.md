**Reading scope:** HTML text extraction: distributed backends, explicit initialization, TCP ring/SSH hostfile and JACCL requirements.

## Findings and limitations

**Source-reported:** The MLX ring backend uses TCP sockets and mlx.launch uses SSH plus a hostfile. JACCL is a separate Thunderbolt RDMA path. A default-any initializer can produce a singleton group.

**Limitations:** Documentation does not establish Wi-Fi collective performance or fault tolerance. Baselines must select a backend explicitly and check world size equals three. Supplements S02 without replacing it. No external benchmark performance has been reproduced by this reading.
