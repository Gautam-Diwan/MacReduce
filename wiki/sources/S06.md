FedNova identifies objective inconsistency when heterogeneous clients perform unequal local work and develops normalized aggregation. For plain SGD, the reviewed normalization separates intended client weights from local-step counts. This is not a universal recipe for Adam or arbitrary momentum solvers. MacReduce must define dataset weights before optimizing throughput.
