# M1 GPU pilot and failed real-Qwen3 ANE correctness gate

**Measured locally:** M1 MacBook Air, 8 GiB, macOS 27.2.1; MLX 0.32.4,
mlx-lm 0.32.2, ANEForge 0.4.0. The [raw report and reproduction commands](../../evidence/m1-training-2026-11-10/README.md)
record versions, exact scope, checkpoints, telemetry limitations, failed
attempts, and the final matched pair. This extends the earlier
[MLX verification](2026-11-10-m1-mlx.md), without rewriting it.

**GPU pilot:** pinned Qwen3-0.6B 4-bit, rank 8/scale 2, batch 1, sequence 128,
checkpointing, seed 0; 10 updates and 1,086 training tokens drawn from the first
32 nonempty WikiText records. On the same fixed two test batches, perplexity
went from 97.5221 to 73.5956. Peak MLX allocations were 687,620,656 bytes.
Checkpoints at steps 5 and 10 contain finite adapters. This is not a
three-epoch or full-split quality result.

**Hybrid pilot, rejected:** same token counts and initial sampled loss;
27 blocks on GPU, block 27 compiled with the ANE mask for forward/backward.
Ten updates completed, sampled perplexity reached 112.5949, and peak MLX
allocations were 1,362,022,595 bytes. Median reported step times were 497 ms
(GPU) and 627 ms (hybrid), one pilot per arm. Invalid math, cache/compile state,
and sample size preclude a useful-training speed comparison.

**Real-model correctness failure:** three real WikiText batches at GPU adapter
steps 0, 5, and 10 had ANE/GPU suffix-output cosine 0.914–0.920. ANE LoRA
gradients were zero despite nonzero GPU gradients. The suffix output equaled
its input. An isolated ANE input RMSNorm also returned all zeros for these
inputs, whose maxima were 5,760–6,624, while the GPU norm was nonzero. The
saved hybrid block-27 B factors remained zero. The [detailed diagnostic](../../evidence/m1-training-2026-11-10/qwen-norm-parity.json)
localizes a failure but does not establish an overflow mechanism. Reference:
quantized GPU block, not a full float64 decoder oracle. This M1 finding does
not revise the older M4 RMSNorm measurements.

**Small ANE gates passed:** linear forward/gradient/SGD against NumPy at input
scales 0, 0.01, 1, 4, plus 100 finite fixed-batch updates. The existing tiny
decoder forward/finite-difference test passed too. These gates missed the
real-Qwen3 failure; finiteness and device masks do not establish correctness.

**Implementation corrections:** data now downloads the pinned immutable
WikiText parquet files and verifies SHA-256 before parsing. The former helper
recorded a revision but did not request it. Sampling RNG now isolates backend
setup, training order, and fixed evaluation batches; earlier uncontrolled
pilots remain retained but are superseded for comparison. PyArrow is in the
serving extra/lockfile. The M1 hybrid config now requires a passing real-block
gradient report; its failed report blocks another ordinary training launch.

**Resources:** a GPU attempt stopped after >512 MiB swap growth; the user saved
work and closed heavy apps before the successful retry. A hybrid attempt
stopped under the original 15 GiB disk gate; the user explicitly selected
10 GiB for later smoke runs. Other stop limits stayed unchanged. No personal
apps/files were closed/deleted by the agent. No system security, memory, or fan
settings changed. ANEForge's initial default cache (~139 MiB) was preserved;
later compilations use the ignored project directory. Memory limits are
best-effort and do not bound total process or compiler memory.

**Unknown/blocked:** no accepted energy ranking (ANE/CPU/DRAM power channels
reported zero without independent validity); no independent full-Qwen3 ANE
trainer; no split-client execution; no 4,096-line three-epoch study. Following
the [ANE stop gate](../guides/ane.md), longer hybrid experiments stop until
real-model normalization/backward correctness is restored. A separate ANE
client also needs a compatible full-model executor, adapter state lifecycle,
and recovery tests. [Single-machine workflow](../guides/single-machine.md),
[state](../project/state.md).

**Software validation:** 114 passed, 5 skipped in the final default suite;
hardware checks were run separately as scoped above. Project-code Ruff,
structural wiki lint and offline lockfile validation passed. Whole-tree Ruff
retains 13 existing immutable-source violations. The inherited SciPy/NumPy
pair emitted one warning. Passing these checks does not repair or override
the observed real-model numerical failure.
